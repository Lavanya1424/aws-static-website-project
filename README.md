# AWS S3 Static Website Hosting Project

## Project Overview
This project demonstrates how to host a static website using AWS S3 and manage source code using GitHub.

## Technologies Used
- HTML
- CSS
- AWS S3
- GitHub

│
└── images/
    └── logo.png

## Features
- Static Website Hosting
- Public Access Configuration
- CSS Styling
- Image Integration
- GitHub Version Control
